# M5 Cardputer Macro Pad 

Программируемый USB HID макропад для **M5Stack Cardputer** на ESP32.

Проект превращает Cardputer в компактную аппаратную панель быстрого запуска: макросы можно создавать, редактировать, перемещать, удалять, назначать им физические trigger-комбинации и сохранять во Flash.

## Возможности

- USB HID клавиатура.
- До **30 макросов**.
- До **24 действий** в одном макросе.
- Типы действий:
  - `KEY` — одиночная клавиша.
  - `COMBINATION` — комбинация с Ctrl / Shift / Alt / Win.
  - `TEXT` — печать текста на ПК.
  - `DELAY` — задержка в миллисекундах.
- Захват реальных клавиш Cardputer и комбинаций.
- `Fn` в записываемой комбинации интерпретируется как `Win/GUI`.
- Настраиваемый trigger для каждого макроса.
- Переименование макросов.
- Перемещение макросов.
- Перемещение действий вверх/вниз.
- Удаление действий.
- Полноценная навигация по меню.
- Страницы макросов по 10 элементов: `0–9`, `10–19`, `20–29`.
- Быстрый запуск выбранного макроса через `SPACE`.
- Выбор макроса по номеру.
- Режим обычной USB-клавиатуры.
- Сохранение конфигурации во Flash через `Preferences`.
- Встроенные IT/Windows-макросы.
- Восстановление стандартных макросов.
- Экран справки прямо на устройстве.

## Аппаратные требования

- M5Stack Cardputer.
- USB-C кабель с поддержкой передачи данных.
- ПК с USB HID.

## ПО

Рекомендуемая среда:

- Arduino IDE.
- ESP32 Arduino Core.
- Библиотека `M5Cardputer`.

Используемые библиотеки:

```cpp
#include <Arduino.h>
#include <M5Cardputer.h>
#include <USB.h>
#include <USBHIDKeyboard.h>
#include <Preferences.h>
#include <vector>
```

Проект рассчитан на API Cardputer, используемый текущей версией проекта:

- `M5Cardputer.update()`
- `Keyboard.isChange()`
- `Keyboard.isPressed()`
- `Keyboard.keysState()`
- `KeysState::word`
- `KeysState::hid_keys`
- `KeysState::fn`
- `KeysState::ctrl`
- `KeysState::alt`
- `KeysState::shift`

`KeysState::word` и `KeysState::hid_keys` обрабатываются как STL-векторы. Это важно для совместимости с установленной библиотекой M5Cardputer.

## Установка

1. Откройте `M5-Cardputer-Macro-Keypad_V4_8.ino` в Arduino IDE.
2. Выберите плату M5Stack/ESP32, соответствующую вашему Cardputer.
3. Установите библиотеку `M5Cardputer`.
4. Подключите Cardputer по USB.
5. Скомпилируйте и загрузите прошивку.
6. После загрузки откройте Serial Monitor при необходимости диагностики.

Для устройства не требуется отдельный USB host-контроллер: Cardputer используется как физическая клавиатура управления, а ESP32 выставляет USB HID Keyboard на ПК.

## Главный экран

На основном экране макросы разбиты на страницы по 10 элементов:

```text
PAGE 1:  0–9
PAGE 2: 10–19
PAGE 3: 20–29
```

### Навигация

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | Выбрать макрос |
| `0–9` | Выбрать слот на текущей странице |
| `SPACE` | Запустить выбранный макрос |
| `ENTER` | Открыть редактор макроса |
| `TAB` | Следующая страница |
| `Shift+TAB` | Предыдущая страница |
| `Fn+;` | Предыдущий макрос |
| `Fn+.` | Следующий макрос |
| `Fn+N` | Создать новый макрос |
| `Fn+M` | Переключить `MACRO / KEYBOARD` |
| `ESC` | Назад / отмена |

`Fn+;` и `Fn+.` на главном экране специально используются именно как переключение предыдущего/следующего макроса.

## Выбор макроса по номеру

В проекте предусмотрен отдельный picker макросов.

Можно ввести номер макроса и нажать `ENTER`.

Примеры:

```text
1  -> первый макрос
9  -> девятый
10 -> десятый
17 -> семнадцатый
30 -> тридцатый
```

`ESC` закрывает picker без изменения выбора.

## Редактирование макроса

После `ENTER` открывается меню выбранного макроса.

```text
Actions
Set trigger
Rename
Enabled
Run macro
Move macro up
Move macro down
Delete macro
Save
Back
```

### Управление меню

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | Перемещение по пунктам |
| `ENTER` | Выбрать пункт |
| `ESC` | Вернуться назад |

### Actions

`Actions` открывает список действий макроса.

```text
1  COMBO Win+R
2  DELAY 600ms
3  TEXT cmd
4  KEY ENTER
+  Add action...
```

`↑/↓` перемещают курсор, `ENTER` открывает выбранное действие или добавление нового, `ESC` возвращает в меню макроса.

## Меню действия

Для выбранного действия открывается отдельное меню:

```text
Edit action
Move up
Move down
Delete action
Add action
Back
```

Таким образом действие можно редактировать не только горячими клавишами, но и обычным меню.

### Горячие клавиши действий

| Клавиша | Действие |
|---|---|
| `Ctrl+N` | Добавить действие |
| `Ctrl+D` | Удалить действие |
| `Ctrl+↑` | Переместить действие вверх |
| `Ctrl+↓` | Переместить действие вниз |
| `Ctrl+S` | Сохранить |
| `ESC` | Назад |

## Добавление действия

Меню `Add action` содержит:

```text
KEY
COMBINATION
TEXT
DELAY
```

Навигация:

- `↑/↓` — выбор типа.
- `ENTER` — создать действие.
- `ESC` — отмена.

Быстрые варианты также предусмотрены через `Fn+F1...Fn+F4`:

| Сочетание | Тип |
|---|---|
| `Fn+F1` | KEY |
| `Fn+F2` | COMBINATION |
| `Fn+F3` | TEXT |
| `Fn+F4` | DELAY |

## Захват клавиш

При создании `KEY` или `COMBINATION` открывается экран захвата.

Примеры:

```text
R
ENTER
F5
CTRL+C
CTRL+SHIFT+ESC
ALT+TAB
Fn+R
```

При записи:

- `Ctrl` сохраняется как `MOD_CTRL`.
- `Shift` сохраняется как `MOD_SHIFT`.
- `Alt` сохраняется как `MOD_ALT`.
- `Fn` сохраняется как `MOD_GUI` (Win).

### Отмена захвата

`ESC` — отменить.

Для случаев, когда сама клавиша Escape должна использоваться как данные, предусмотрена дополнительная комбинация отмены в интерфейсе захвата: `Ctrl+Alt+Backspace`.

## KEY vs COMBINATION

`KEY` предназначен для одиночной клавиши.

Пример:

```text
ENTER
F5
ESC
A
```

`COMBINATION` предназначен для комбинации:

```text
CTRL+C
CTRL+SHIFT+ESC
ALT+TAB
WIN+R
```

## TEXT

`TEXT` отправляет строку на ПК через USB HID.

Примеры:

```text
cmd
powershell
ipconfig /all
hello@example.com
```

Ограничение одного текстового действия:

```text
180 символов
```

Текст зависит от текущей раскладки клавиатуры Windows. Для команд Windows рекомендуется английская раскладка.

## DELAY

`DELAY` задаётся в миллисекундах.

Примеры:

```text
100   = 0.1 сек
500   = 0.5 сек
1000  = 1 сек
5000  = 5 сек
```

Максимальная задержка одного действия — `60000 ms`.

## Запуск макроса

Есть несколько способов:

1. Выбрать макрос и нажать `SPACE`.
2. Назначить trigger и нажимать назначенную комбинацию.
3. Выбрать макрос и запустить его из меню `Run macro`.

После выполнения устройство дополнительно вызывает `releaseAll()`, чтобы USB-клавиши не оставались физически зажатыми.

## Trigger

У каждого макроса может быть свой trigger.

Примеры:

```text
WIN+F1
WIN+F2
CTRL+ALT+T
SHIFT+WIN+F5
```

Trigger назначается через:

```text
Edit Macro
  -> Set trigger
```

После входа устройство ждёт физическое нажатие комбинации на Cardputer.

## Режим MACRO / KEYBOARD

`Fn+M` переключает режим.

### MACRO

Cardputer работает как макропад:

- навигация по меню;
- запуск макросов;
- редактирование;
- trigger-макросы.

### KEYBOARD

Cardputer используется как обычная USB HID клавиатура.

Это удобно, когда нужно использовать Cardputer как компактную клавиатуру и временно не пользоваться меню макросов.

## Trigger встроенных макросов

Стандартная библиотека использует Win/GUI-модификатор:

```text
GUI + F1 ... F12
```

Для дополнительных макросов 20–29 используются:

```text
GUI + SHIFT + F1 ... F10
```

На Cardputer записанный `Fn` хранится как `MOD_GUI`, то есть как Win/Windows key для USB HID.

## Исправление Win+R / Enter

В проекте специально учтена важная особенность USB HID API.

HID usage ID и значение, которое принимает `USBHIDKeyboard.write()/press()`, не всегда совпадают.

Например:

```text
HID R = 0x15
```

Нельзя просто отправить:

```cpp
usbKeyboard.write(0x15);
```

Вместо этого проект преобразует HID usage `R` в ASCII:

```text
0x15 -> 'r'
```

То же самое для Enter:

```text
HID_ENTER (0x28) -> KEY_RETURN
```

Это устраняет ошибочное поведение, при котором команда в Windows Run могла превращаться в `cmd(`.

## Основные структуры

### MacroAction

```cpp
struct MacroAction {
  uint8_t type;
  uint8_t key;
  uint8_t modifiers;
  uint16_t delayMs;
  String text;
};
```

### Macro

```cpp
struct Macro {
  String name;
  uint8_t triggerKey;
  uint8_t triggerModifiers;
  MacroAction actions[MAX_ACTIONS];
  uint8_t actionCount;
  bool enabled;
};
```

## Ограничения

```text
MAX_MACROS    = 30
```

## Безопасность

Проект предназначен для локальной автоматизации и диагностики.

Встроенные команды могут:

- запускать системные оснастки Windows;
- открывать CMD/PowerShell;
- запускать диагностические команды;
- выполнять команды проверки/диагностики системы.

Проект не реализует:

- получение паролей;
- обход UAC;
- скрытую персистентность;
- скрытую передачу данных;
- отключение защитных средств;
- удалённое управление компьютером.

Пользователь сам отвечает за команды, которые добавляет в `TEXT` и макросы.

## Устранение проблем

### Arduino сообщает об ошибке `s.word.length()`

Такого обращения в актуальной версии быть не должно.

`KeysState::word` является `std::vector<char>`, поэтому используются:

```cpp
s.word.empty()
s.word.size()
s.word[i]
```

### Win+R работает неправильно

Убедитесь, что используется актуальная версия проекта. Прямой HID usage код `R` не должен передаваться как ASCII-значение.

### Enter вводит неправильный символ

Проект специально преобразует:

```text
HID_ENTER -> KEY_RETURN
```

### Макрос ничего не делает

Проверьте:

1. Макрос включён (`Enabled = ON`).
2. Выбран правильный макрос.
3. Trigger назначен.
4. Cardputer подключён к ПК через USB.
5. В Windows не перехватывается нужная комбинация другой программой.
6. Для административных команд программа действительно запущена с необходимыми правами.

### Текст печатается неправильными символами

Проверьте раскладку Windows. Для системных команд используйте английскую раскладку.
